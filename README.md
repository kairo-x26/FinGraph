# FinGraph

Document intelligence and compliance evidence platform for KYB/KYC reviews.

FinGraph ingests financial and compliance documents, extracts structured facts with
source references, links companies and people in an evidence-backed knowledge graph,
and answers analyst questions with citations. Reviewers stay in control of every
decision.

Status: early development. See [docs/PLAN.md](docs/PLAN.md) for the build plan.
